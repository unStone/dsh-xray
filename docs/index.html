这是什么

dsh-xray 对 dsh-plugin 生态做静态能力分析:注入了哪些服务、挂了哪些钩子、是否给 runtime 打补丁、外联哪些域名、读哪些凭证类环境变量、有没有安装期脚本。能力等级(C0–C3)衡量的是能力面大小与透明度,不是恶意判定——一个 C3 插件完全可能是正当的,它只是同时拥有强能力和需要你知情的行为。

等级说明

C0 无显著能力面 · C1 常规(注册工具/服务/外联) · C2 强能力(改系统提示词 / 拦截 API / 子进程 / exec / 凭证读取 / 安装脚本,其一) · C3 强能力与敏感行为并存。每个标志都附代码位置证据,可复核、可申诉。

给插件作者

在 README 挂上你的能力徽章,让用户一眼看到透明度报告——展开任意插件行即可复制徽章代码。误报请提 issue,我们会复核并修正规则。
